CDAS documentation
==================

CDAS is a companion package to DASCORE that adds support for compressed DAS data. CDAS includes:
- IO support for `.zfp` file extensions containing DAS data compressed with the ZFP compression codec
- Support for reading and writing compressed DAS data to and from `.zfp` files
- More features coming soon!

Installation
------------
Install from PyPI:

.. code-block:: bash

   pip install cdas


Install from source:

.. code-block:: bash

   git clone https://github.com/byron-selvage/cdas.git
   cd cdas
   pip install -e .
